# Проект "QESPy Project"

Добро пожаловать в проект "AwesomeApp"! Это приложение для управления задачами.

## Установка
1. Склонируйте репозиторий.
2. Установите зависимости с помощью `npm install`.
3. Запустите приложение командой `npm start`.

## Использование
- Создайте новую задачу.
- Отметьте выполненные задачи.
- Просмотрите список всех задач.
